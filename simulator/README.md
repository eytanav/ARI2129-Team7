## Instructions:

1. Change directory to simulator folder (note: Current directory should be main project folder)
Windows -> cd simulator
MacOS / Linux -> cd simulator

2. Set up a python environment: 
Windows -> python -m venv sim_env
MacOS / Linux -> python3 -m venv sim_env

3. Activate the environment:
Windows -> .\sim_env\Scripts\activate
MacOS / Linux -> source sim_env/bin/activate

4. Install dependencies:
pip install -r requirements.txt

5. Run the application:
Windows -> python app.py
MacOS / Linux -> python3 app.py

6. Open the local web address:
http://127.0.0.1:7860
